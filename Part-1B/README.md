# Part 1B: Natural-Language Reminder Agent

The model provider is Google Gemini. Set `GEMINI_API_KEY` and
`MODEL_NAME=gemini-3.5-flash-lite` in your local `.env` file;
`MODEL_API_KEY` is also accepted as a generic key name. This is the model used
for the passing evaluation run.

## Setup
    python -m venv .venv
    source .venv/bin/activate      # Windows: .venv\Scripts\activate
    python -m pip install -r requirements.txt
    # Create .env locally with GEMINI_API_KEY and MODEL_NAME=gemini-3.5-flash-lite.
    # MODEL_API_KEY is also accepted; never commit .env.

## Run the agent
    python -m src.cli "remind me to call mom tomorrow at 5pm"

## Run the evaluation harness
    python .harness/run_eval.py

Results are written to evidence/eval-results/. The threshold is read from .harness/config.json.
